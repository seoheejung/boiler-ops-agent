02 / RUN IT YOURSELF

03실행Kafka → API → 화면 → 재생
04확인로그인 · 관측 · 조회 · 승인
무엇이 실행되어 있어야 하나요?

API 8000 · 화면 5173 · Kafka 9092 · Ollama 11434. 모든 서버는 로컬에서 실행합니다. 브라우저 주소와 APP_PUBLIC_ORIGIN은 같아야 합니다.

03 / BOUNDARIES & EVIDENCE

어디에서 검증하고,
무엇을 막는가.

검증된 범위와 남은 한계를 분리해서 기록합니다. 상세 기록도 페이지 안에서 읽을 수 있습니다.

요청이 통과하는 네 개의 문

  1. 01Origin·Host·입력 크기
  2. 02만료 세션·역할·사용자 소유권
  3. 03요청량·모델 작업·연결·저장 한도
  4. 04근거 나이·재생 세션·단일 사용·revision
Kafka 생산자와 소비자SASL + ACL
질문·Trace·제안·Audit사용자별 접근
키보드·모바일·차트 대체 정보브라우저 검수

로컬 데모에서 검증한 경계입니다. 외부 배포, 실제 스크린리더 낭독, 설비 제어의 안전성을 인증하는 결과는 아닙니다.

예측 성능 재검토

실사용 접근성 확인
