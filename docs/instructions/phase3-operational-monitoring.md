# Phase 3 — Operational Monitoring

재열기 Loop를 첫 온도 분석 대상으로 한다. 실제값은 `최종재열기 입구 온도 평균값`, 목표는 `목표 재열기 온도`이며 서로 같은 계측 지점이라는 주장은 하지 않는다.
목표 온도는 원본 전체에서 결측이므로 비교표에서 결측으로 표시한다. 발전량은 실제·목표 모두 존재해 편차를 계산한다.
관련 제어값은 동일 Event의 관측값으로 연결한다. 상관관계·제어 효과를 주장하지 않는다.
변화율은 source_time 경과 분 기준, 분포 편차는 최신값을 제외한 수신 이력으로 계산한다. 안전 임계값을 만들지 않는다.

실제 Kafka/브라우저 E2E에서 시간 정렬, 실제·목표 편차, 결측 보존, 과거 표본 수와 통계값, 설비 선택 Context를 확인한다.
