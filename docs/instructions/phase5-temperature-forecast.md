# Phase 5 — Temperature Forecast & Advisory

- 대상: `최종재열기 입구 온도 평균값`, Horizon: 원본 시간 5분.
- 비교: 현재값 유지 Naive vs 학습한 직접 5분 선형 자기회귀 모델.
- 시간순 70% 학습, 15% 검증, 15% 시험. 각 구간 경계를 넘는 학습/평가 Pair는 제외한다.
- 검증 MAE로 모델을 선택하고, 시험 MAE/RMSE는 선택에 사용하지 않는다.
- 검증 구간 MAE에서 Naive가 우수하면 Naive를 선택한다. 시험 구간 결과를 선택에 재사용하지 않으며, 성능 개선을 과장하지 않는다.
- 추론은 학습/검증 종료 이후 source_time만 허용한다. 원본 결측·불연속은 학습에서 제외한다.
- Agent는 `get_temperature_forecast` Read Tool로만 예측 결과를 읽는다.
- 목표 온도 결측 및 제어 인과관계 미확인 때문에 구체적인 제어 증감값은 제안하지 않는다.
- E2E는 원본 시험 구간을 실제 Kafka로 재생하여 UI 예측값과 모델 계산·근거를 대조한다.
